# 従業員向け 使い方ガイド

スマートフォンやパソコンから、自分の勤怠の確認と修正申請ができます。
画面下のメニュー（**ホーム / 勤怠 / 申請 / ヘルプ / マイページ**）で画面を切り替えます。

> [!NOTE]
> 出勤・退勤の打刻は、ラボに設置された**打刻端末**（NFC カードまたは顔認証）で行います。この画面から打刻することはできません。

---

## 今日の記録を確認する

**ホーム** を開くと、いちばん上に今日の記録が表示されます。

- **出勤 / 退勤**: 打刻端末で記録された時刻です。まだ打刻していないときは `--:--` と表示されます。
- **勤務時間**: 退勤後に、丸め処理をした勤務時間が表示されます。
- 今日のカードをタップすると、その日の詳細が開きます。

ホームにはほかに、次の内容が表示されます。

- **確認してください**: 打刻もれなど、対応が必要なことがあるときだけ表示されます。タップするとその日の詳細が開きます。
- **今月のまとめ**: 出勤日数、申請勤務時間、4月からの累計時間。
- **次のシフト**: これから先のシフト（最大3件）。
- **最近の勤務**: 直近の勤務。「すべて見る」で **勤怠** 画面に移動します。

## 過去の記録を見る

**勤怠** を開くと、月ごとの記録が1日1行で表示されます。

1. 画面上部の **‹ ›** で月を切り替えます。年月の表示をタップすると、月を直接選べます。
2. 今月の記録は、**今日に近い日が上**に並びます。**「新しい順 ↓」** をタップすると古い順に切り替えられます。
3. 見たい日の行をタップすると、その日の詳細が開きます。

- はじめは、シフトも打刻もない日は省略されています。**「休みの日も表示」** をタップするとすべての日が表示されます。
- これから先のシフトは **「今後のシフト」** にまとめられています。タップすると開きます。
- 週ごとの見出しには、その週の勤務日数と勤務時間の合計が表示されます。

### 1行の見方

- **大きい時刻**（例: `12:52 – 18:07`）: 出勤と退勤の打刻時刻です。退勤がまだのときは `--:--` と表示されます。
- **シフト**（例: `13:00〜18:00`）: その日のシフト予定です。
- **右側の時間**（例: `5:00`）: その日の勤務時間（丸め処理後）です。
- **色つきのラベル**: その日の状態です（下の表を参照）。
- **修正申請中** / **要確認**: 承認待ちの修正申請がある日、確認が必要な勤務があった日に表示されます。

### 状態ラベルの意味

| ラベル | 意味 |
| :--- | :--- |
| **正常** | シフトどおりに出勤・退勤しました |
| **勤務中** | 出勤の打刻があり、まだ退勤していません |
| **出勤予定** | シフトがあり、まだ打刻がありません |
| **遅刻 / 早退** | シフト開始より後に出勤、またはシフト終了より前に退勤しました |
| **打刻もれ** | 出勤か退勤のどちらかの打刻がありません。**修正申請が必要です** |
| **欠勤** | シフトがありましたが打刻がありません |
| **休み** | シフトも打刻もない日です |

## 打刻を修正したいとき（修正申請）

打刻を忘れた、時刻が違う、というときは **修正申請** をします。管理者が承認すると記録に反映されます。

1. **ホーム** または **勤怠** で、修正したい日をタップします。
2. **「修正を申請する」** をタップします。
3. **正しい出勤時刻** と **正しい退勤時刻** を入力します。
   - 変更しないほうは、そのままにしてください。
   - **「シフト開始」「シフト終了」** をタップすると、シフトの時刻をそのまま入力できます。
   - 余分な打刻を消したいときは **「空欄にする」** をタップします。
4. **修正の理由** を入力します（必須）。例: 「退勤時にカードをかざし忘れました」
5. **「申請する」** をタップします。

> [!TIP]
> 申請の前に「申請後の勤務時間（目安）」で、勤務時間がどれだけ変わるかを確認できます。

> [!IMPORTANT]
> - 承認を待っているあいだは、同じ記録に重ねて申請することはできません。内容を変えたいときは、いったん申請を取り消してからやり直してください。
> - 管理者が月を締めたあとは、その月の修正申請はできません。
> - 打刻の記録がまったくない日（欠勤と表示されている日）は、この画面から申請できません。勤務していた場合は管理者に連絡してください。

## 申請の結果を確認する・取り消す

**申請** を開くと、自分の修正申請の一覧が表示されます。

- **承認待ち / 承認済み / 却下 / すべて** をタップして絞り込めます。
- 却下されたときは、管理者からのコメントが表示されます。
- 承認待ちの申請は **「取り消す」** で取り消せます。
- 結果は画面右上の **ベルのマーク**（お知らせ）にも届きます。

## 休憩を記録する

勤務中に休憩を取ったときは、勤務時間から休憩時間を差し引けます。

1. 対象の日をタップして詳細を開きます。
2. **「休憩60分を追加」** をタップします。
3. 取り消すときは、同じ場所の **「休憩を取り消す」** をタップします。

## 記録が変更された履歴を見る

- ある日の記録の履歴: その日の詳細で **「変更履歴」** をタップします。
- 月ごとの履歴: **申請** の **「編集ログ」** をタップします。修正申請の承認や、管理者による修正の内容が新しい順に並びます。

勤務の記録は給与計算のもとになるため、いつ・誰が・なぜ変更したかがすべて残ります。

## 勤務時間の数え方

- 勤務時間は `時間:分` の形式で表示されます（例: `5:15` は 5時間15分）。
- **出勤**はシフト開始より前に打刻してもシフト開始からの計算になり、シフト開始より後のときは5分単位で切り捨てます。
- **退勤**はシフト終了より後に打刻してもシフト終了までの計算になり、シフト終了より前のときは5分単位で切り上げます。
- **申請勤務時間**は、その月の勤務時間の合計を30分単位で切り上げた時間で、給与計算に使われます。「実時間」は切り上げ前の合計です。
- **4月からの累計**は、年度の初め（4月1日）から今月末までの申請勤務時間の合計です。

その日の詳細に「計算上の勤務」と表示されているときは、打刻時刻と計算に使われた時刻が違うことを示しています。

## 「要確認」と表示されたとき

次のような勤務があると、その日や週に「要確認」と表示されます。管理者が内容を確認するためのお知らせで、あなたが操作する必要はありません。

- 9時より前の出勤、19時を過ぎた退勤
- 1日の勤務が5時間または6時間を超えたとき（6時間を超えたときは休憩が必要です）
- 週に4日以上の出勤、週の合計が18時間を超えたとき

## プロフィール・カード・顔認証

**マイページ** では次のことができます。

- **プロフィール情報**: 表示名・氏名・フリガナ・所属・従業員IDの変更
- **NFCカード**: 打刻に使うカードの登録（カードリーダーをつないだパソコンの Chrome / Edge が必要です）
- **顔認証データ**: 打刻端末で顔認証を使うための顔の登録・削除・テスト（スマートフォンのカメラでも登録できます）
- **メールアドレス変更**: 新しいアドレスに確認メールが届きます
- **ログアウト**

## 困ったときは

- **今日の打刻が表示されない**: ブラウザで画面を再読み込みしてください（別のアプリから戻ってきたときは自動で最新の内容に更新されます）。それでも表示されないときは、打刻端末で打刻できていない可能性があります。
- **「この月は締め処理が済んでいる」と表示される**: 管理者が月を締めたあとは修正できません。管理者に相談してください。
- **「すでに承認待ちの申請が存在します」と表示される**: 同じ記録への申請が残っています。**申請** 画面で確認してください。
- **「時間帯が重複しています」と表示される**: 同じ日のほかの勤務と時間が重なっています。時刻を見直してください。
