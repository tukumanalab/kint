# 勤怠一覧画面 使い方ガイド

本ドキュメントでは、「勤怠管理（勤怠一覧）」画面の操作方法や仕様について解説します。
本システムでは、ログインしているアカウントの権限（管理者 / 一般従業員）によって行える操作が異なります。

---

## 1. 勤怠記録の修正方法

打刻漏れ（出勤または退勤の押し忘れ）や押し間違いがあった場合、以下の手順でデータを修正できます。

### 【一般従業員】修正申請を行う
一般従業員は、自身の過去の勤怠データを直接書き換えることはできません。管理者に「修正申請」を提出し、承認されることで反映されます。

1. 日別勤怠詳細の一覧から、修正したい日の行にある **「修正申請」** ボタンをクリックします。
   - 1日に複数回の打刻（中抜けなど）がある場合は、修正したい特定の打刻レコードの「修正申請」をクリックします。
2. 表示されるモーダルで、以下の情報を入力します。
   - **出勤希望時刻** / **退勤希望時刻**: 修正後の正しい時刻を指定します。
     - 出勤のみ、または退勤のみの修正も可能です。
     - 打刻ミスで余分に記録されたデータを消したい場合は、**「クリア」** ボタンで空欄にすることができます。
   - **申請理由 (必須)**: 修正が必要になった理由（例: 「カード忘れのため手動申請」「退勤押し忘れ」など）を詳しく入力します。
3. **「申請する」** ボタンをクリックすると、管理者に申請が送信されます。

> [!NOTE]
> - 申請中は、対象日に `承認待ち` バッジが表示され、管理者が承認または却下するまで追加の修正申請は行えません。
> - 申請内容（変更後の勤務時間の増減など）は、申請前にプレビューで確認できます。

### 【管理者】直接追加・編集・削除を行う
管理者は、申請ワークフローを経由せずに、直接勤怠データを追加・修正・削除できます。

- **直接修正・削除**:
  1. 日別詳細の対象行にある **「修正」** ボタンをクリックします。
     - モーダルで「打刻（実時刻）を修正（勤務時間は自動計算）」するか「勤務時間（丸め後）を手動で直接指定」するかを選択します。
     - 時刻を入力して保存します。
  2. 不要なレコードは **「削除」** ボタンでデータベースから直接削除できます。
- **新規追加**:
  - 打刻レコード自体が存在しない日（欠勤日や打刻漏れの日）に新規に勤務を追加したい場合、**「追加」** ボタンをクリックします。
     - モーダルで「打刻（実時刻）を追加（勤務時間は自動計算）」するか「勤務時間（丸め後）を手動で直接指定」するかを選択し、時刻を新規登録できます。

> [!NOTE]
> **勤務時間（手動指定）を追加・修正した際の実打刻（実時刻）との連動**
> 「勤務時間（丸め後）を手動で直接指定」を選択して追加・修正した場合でも、ファイル出力（CSVエクスポート等）において勤務時間計算や打刻時刻出力が正常に行われるよう、システム内部では「実出勤打刻 / 実退勤打刻」のフィールドにも指定した「勤務出勤日時 / 勤務退勤日時」と同じ値が同時に自動でセットされます。

> [!WARNING]
> **締め処理（ロック）中の制限**
> 対象年月が「締め済（ロック）」状態になっている場合、管理者であっても直接編集や申請の承認を行うことはできません。修正を行う場合は、先に締め処理を解除する必要があります。

> [!IMPORTANT]
> **時間帯が重複しています（ATTENDANCE_OVERLAP）と出る場合**
> 同一日に既に登録されている他の勤務時間帯と一部でも重なる時間帯で新規追加や修正、申請を行おうとすると、重複登録防止の安全機能によりエラーが発生して保存できません。先に既存の重複するレコードの時刻を調整するか、不要なレコードを削除してから再度操作を行ってください。

## 2. 勤怠記録の「履歴」の意味

各勤怠データの横にある **「履歴」** ボタンをクリックすると、そのレコードの「変更履歴（監査ログ）」を確認できます。

### 履歴に記録される情報
- **変更日時** と **操作を実行したユーザー**（申請者および承認した管理者、または直接修正した管理者）
- **変更前** および **変更後** の出勤・退勤時刻
- **申請理由**（従業員が入力したもの）
- **承認・却下コメント**（管理者が入力したもの）

### なぜ履歴が必要なのか？
勤務データは給与計算の根拠となる重要な情報です。改ざんや誤入力を防ぎ、いつ・誰が・どういう理由でデータを修正したかを完全に可視化（監査トレール）することで、健全で透明性の高い勤怠管理を実現しています。

## 3. 打刻元（Source）の意味

勤怠一覧に表示される「打刻元」は、その勤怠データがどのような方法で記録されたかを示しています。

| 表示される打刻元 | 意味・記録方法 |
| :--- | :--- |
| **NFC (PaSoRi)** | 打刻端末のICカードリーダー（PaSoRi）にFeliCaカードをかざして打刻された正規の記録。 |
| **Web打刻 (ID入力)** | ブラウザの打刻画面から、手動で従業員ID（メールアドレス等）を入力して打刻された記録。 |
| **自己申告** | 一般従業員が「修正申請」を行い、管理者がそれを承認して反映された記録。 |
| **管理者修正** | 管理者が管理画面から直接追加、あるいは修正した記録。 |
| **自動補完** | 出勤打刻はあるが退勤打刻がないまま日を跨いだ場合などに、システムスケジュール等によって自動的に退勤処理された記録。 |

## 4. その他、画面で使い方に困りそうなこと

### Q. 月次サマリーに表示される「申請勤務時間(実時間)」と「総勤務時間(4月〜)」とは何ですか？
月次サマリーテーブルやモバイルカード、個人サマリーカードには、以下の勤務時間が集計・表示されます。
*   **申請勤務時間(実時間)**:
    *   その月に実際に勤務した時間を合計して **30分（0.5時間）単位で切り上げた** 時間で、給与計算に利用されます。
    *   カッコ内の時間は、その月に実際に勤務した各日の合計時間（実勤務時間）です。
    *   `30分切り上げ時間 (切り上げ前の実時間)` 形式（例: `144:00 (143:45)`）で表示されます。
*   **総勤務時間(4月〜)**:
    *   当年度期首（4月1日）から当月末までの期間における **申請勤務時間の累計** です。
※CSVエクスポート（サマリー）では、二次利用や計算のしやすさを考慮し、`申請勤務時間` (切り上げ後) と `実勤務時間` (切り上げ前) の2つの別々のカラムに分割して出力されます。

### Q. カレンダーのところどころに挟まっている「週次集計」行は何ですか？
日曜日、または月の最終日の行の下に、その週（月曜日から日曜日まで）の「勤務日数」と「勤務時間の合計」が自動で計算されて挿入されます。週ごとの勤務状況の目安などを把握するためにご活用ください。
※勤務時間の表示形式は、Excel等と共通の `[h]:mm` 形式（例: `8時間15分` の場合は `8:15`、`162時間30分` の場合は `162:30`）となっております。

### Q. カレンダーやサマリーの表に出る「要確認」とは何ですか？
システムが自動的に「注意が必要な勤怠状況（アラート）」を検出し、お知らせする機能です。
以下のルールに該当する場合、該当日の詳細カレンダーや月次サマリーに赤文字で「要確認」と件数・メッセージが表示されます。
*   **日次アラート**: 19時を過ぎての退勤、9時前からの出勤、1日5時間超過、または6時間超過の勤務（6時間超過の場合は休憩が必要な旨も併記されます）。
*   **週次アラート**: 週に4日以上の出勤、週の合計勤務時間が18時間超過。

これらの判定は、打刻時刻ではなく「丸め処理後」や「管理者が手動修正した後の勤務時間」を基準として正確に計算されます。

#### 【管理者向け】確認済チェックボックスについて
詳細カレンダーの「要確認」に表示される各アラートの左側に、**確認済チェックボックス**が表示されます。
- 管理者は内容を確認し、問題がないと判断したアラートのチェックボックスにチェックを入れることができます（一般従業員はチェックできません）。
- チェックを入れると、アラートメッセージに打ち消し線が引かれ、月次サマリー一覧の「**未 / 要確認数**」の「未」（未確認アラート件数）から差し引かれます。
- 「未 / 要確認数」の表示形式は `未確認数 / 総アラート数`（例: `1 / 3`）となっており、月次の勤怠締め作業の前に、未確認のアラートが残っていないかを確認する指標として活用できます。

### Q. 【管理者向け】「月を締める（ロック）」とは何ですか？
月末になり、その月の勤務データが確定した段階で、管理者が「月を締める」を実行します。
- ロックを行うと、その月の勤怠データは一切編集できなくなります（従業員の修正申請、キャンセル、管理者の直接編集すべてがブロックされます）。
- 給与計算中に過去のデータが誤って変更されるのを防ぐための重要な操作です。
- 締め処理を実行した際、まだ承認待ち（pending）的の申請が残っている場合は、**「当月の締め処理が完了したため、システムにより自動的に却下されました。」** という理由で自動的に却下されます。

## 5. 【管理者向け】勤務時間報告書 CSV インポート

管理者は、外部の『勤務時間報告書』形式の CSV ファイル（`氏名,勤務開始日時,勤務終了日時`）を一括アップロードして勤怠記録を登録・上書きできます。

### 操作手順
1. 勤怠管理画面の右上の **「📥 報告書CSVインポート」** ボタンをクリックします。
2. 表示されるモーダルダイアログで対象の CSV ファイルを選択し、**「インポート実行」** をクリックします。
3. インポート完了後、取り込み成功件数、上書き件数、およびアカウントが見つからなかった未登録ユーザーの氏名一覧が表示されます。

### 特記事項・ルール
- **氏名のスペース無視**: CSV内の氏名に含まれる空白（スペース）は無視され、ユーザーの `full_name` と照合されます。
- **重複上書き**: 同一ユーザーの同日（`work_date`）に勤怠データが存在する場合は、新しい出退勤打刻で上書き更新（`source: 管理者修正`）されます。
- **実働時間数**: CSVの「実働時間数」列は使用されず、出退勤打刻を基に自動丸め計算が行われます。

## 6. 【管理者向け】月次勤怠サマリーの確認と CSV エクスポート

管理者は、全従業員の当月勤怠サマリーを一括して一覧確認し、給与計算や提出用の CSV ファイルとしてエクスポート（ローカル保存）できます。

### 6-1. 画面上の月次サマリー項目と見方
勤怠管理画面の上部にある月次サマリーテーブルには、以下の集計データが表示されます。

*   **所定 / 出勤 / 欠勤 / 不整合**: 当月の予定シフト日数、実際の出勤日数、シフトがあったものの打刻がない欠勤日数、および退勤打刻漏れ等の不整合件数。
*   **未 / 要確認数**: その月に発生した勤怠アラートの `未確認数 / 総アラート数`。管理者は詳細カレンダーから内容を確認して「確認済」にチェックを入れることができます。
*   **申請勤務時間(実時間)**:
    *   給与計算の基準となる **30分（0.5時間）単位で切り上げた月間勤務時間** と、カッコ内には切り上げる前の **実際の各日合計勤務時間（実時間）** が表示されます。
    *   表示例: `144:00 (143:45)` （30分切り上げ後の申請勤務時間が 144時間00分、実時間が 143時間45分）。
*   **総勤務時間(4月〜)**:
    *   当年度期首（4月1日）から当月末までの期間における **切り上げ後申請勤務時間の累計** です。

### 6-2. 月次サマリーの CSV エクスポート仕様
画面右上の **「📤 CSV出力」** ボタンから「サマリー」を選択してダウンロードすると、以下のカラムで数値が出力されます。各項目は Excel 等で集計しやすいよう独立した列に分けられています。

| CSV カラム名 | 説明・出力フォーマット | 例 |
| :--- | :--- | :--- |
| **対象月** | 集計対象の年月 (`YYYY-MM`) | `2026-05` |
| **ユーザーID / 表示名 / 氏名** | 従業員のアカウント識別情報 | `usr_01 / yamada / 山田 太郎` |
| **所定労働日数 / 実出勤日数** | 当月のシフト日数と実際の出勤日数 | `21 / 20` |
| **申請勤務時間** | 30分単位で切り上げ計上された月間総時間 (`[h]:mm`) | `162:30` |
| **実勤務時間** | 30分切り上げを行う前の各日合計実時間 (`[h]:mm`) | `162:15` |
| **総勤務時間(4月〜)** | 4月1日〜当月末までの切り上げ後申請勤務時間の累計 (`[h]:mm`) | `320:00` |
| **時間外労働時間** | 当月の所定時間外労働時間合計 (`[h]:mm`) | `0:00` |
| **遅刻回数 / 早退回数 / 欠勤日数 / 打刻エラー日数** | 各勤怠事由の回数・日数 | `0 / 0 / 1 / 0` |

## 7. 勤務時間報告書（パートタイム職員等勤務時間報告書）の作成・印刷方法

対象年月の勤怠データから、標準様式「教学系予算パートタイム職員等勤務時間報告書」のA4縦帳票を作成・プレビュー・印刷できます。

### 7-1. 報告書の開き方
1. 「勤怠管理」画面を開きます。
2. 上部アクションエリアにある **「📄 勤務時間報告書」** ボタンをクリックします。
   - 管理者は、対象年月および従業員選択ドロップダウンで選択中の従業員の報告書を表示・出力できます。
   - 一般従業員は、選択中の年月の自身の報告書を表示・出力できます。

### 7-2. プレビューと勤務内容の編集
1. **所属・カナ・従業員ID・氏名**: ユーザーアカウント情報（所属・フリガナ・従業員ID・氏名）が自動入力されます。
2. **勤務内容**:
   - 初期状態では、システム設定で登録されたデフォルト勤務内容（初期値: `青学つくまなラボ 利用者対応`）が全勤務行に設定されています。
   - 各行の「勤務内容」および「備考」の入力欄をプレビュー画面上で直接修正・書き換えることが可能です。
   - 上部の一括変更ツールバーから文字列を入力し **「一括適用」** を押すことで、全勤務行に一括設定できます。
3. **合計時間数・計算欄**:
   - **合計時間数**: `実時間`（実際の打刻実働時間の合計）が `(HH:MM)` 形式（例: `(15:00)`）で自動集計されます。
   - **計算欄**: `申請勤務時間`（丸め適用後の総労働時間）が 10進数 hours 形式（例: `15.0`）で自動計算されます。

### 7-3. 印刷および PDF 保存
1. プレビュー画面右上にある **「🖨️ 印刷 / PDF保存」** ボタンをクリックします。
2. ブラウザ標準の印刷ダイアログが起動します。
   - 送信先に「PDF に保存」またはプリンターを選択します。
   - 用紙サイズを **A4**（縦向き）に設定し、印刷またはPDF出力を行います。
